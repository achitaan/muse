# WGS finalizer row-read reuse: one CPU-qualified prototype

Retained MoE Python SHA256 `331148716e8d1ba92b45cd29725be997d44b3a5235af74d75770bb9444100d50`; native CUDA `1e60cf469ebff8d0f1e63a223f41f041374a1f30f90e4201a819ee178353270c`. Candidate CUDA `b6199d97ff4907e55b674e55b1f8f04f38df7f7c90c2f0ed2ac5c5df429d9520` is a prototype, not a runnable submission or replacement incumbent.

The selected large-token WGS path already computes each local route's norm in its finalizer. It reads FP32 ybuf twice: first to form the squared sum, then to apply the normalized route coefficient. This prototype retains the first pass's two float4 values per route in thread-private arrays, and reuses them in the second pass. It introduces 64 source-level live FP32 values per thread in the all-eight-local case.

This differs from the closed tiny-token atomic-norm, helper-register and whole-row experiments. It changes neither where WGS norm sums are formed nor their arithmetic. The exact expression tree for squared sums, warp shuffle order, cross-warp accumulation, epsilon, ascending route reduction and BF16 output conversion remain unchanged. Both passes retain the same qv>=0 mask. Invalid slots are not loaded and their uninitialized retained values are never used. All barriers, generation counters, scratch banks, routing, GEMMs, dispatch and non-WGS fallbacks remain intact. The builder's exact textual inverse restores the original entire source.

One removed logical read costs 4096*4=16 KiB per local route. For C actual local routes the removed request volume is 16 KiB*C. This is not measured HBM traffic or exposed time: ybuf may be in L2. No actual route-count distribution or finalizer duration has been measured for this prototype. The complete MoE hot path is substantial in retained Decode profiles, but that does not establish this finalizer's critical-path fraction.

Paired CPU NVRTC compilation uses unchanged selected MAIN geometry, PRMT scales, DQ7 mode and ring sizes. Both arms have 96 registers, 16-byte stack, 56-byte spill stores, 124-byte spill loads and 45 local-memory instructions. Existing baseline spills remain; the candidate adds none by these compiler metrics. Static global-load instruction count decreases 269 to 253 and instruction count 25088 to 25032. Static counts are not runtime traffic or speedups. GPU occupancy/resources and compiler behavior still need actual qualification.

The first CPU baseline compile required a forward declaration of wgs_cta_of under NVRTC lookup rules; its raw error log is retained. The declaration is applied identically to both compiler inputs and is absent from production prototype source. Both subsequent compiles succeeded. A report-only `name` versus `symbol` key error was corrected by reconstructing the report from saved raw logs/CUBIN/SASS, without recompilation. Three compiler invocations total; no parameter sweep or GPU jobs.
